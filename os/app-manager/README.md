## `app-manager`

- Runs the apps
- Keeps track of running apps
- Unloads apps when memory is low

The import format for third-party publisher certificates is specified in
[`THIRD_PARTY_CERTIFICATE_FORMAT.md`](THIRD_PARTY_CERTIFICATE_FORMAT.md).
